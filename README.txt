CREST TIMETABLE FILES

Included:
- timetable.html — student timetable page. It reads published timetable entries from the main CREST Supabase project.
- index_timetable_patch.txt — the small dashboard link needed to open the timetable from the student workspace.
- crest_timetable_setup.sql — database setup script for reference only.

IMPORTANT:
You have already run the timetable SQL successfully in your MAIN CREST Supabase project. Do NOT run it again.

UPLOAD:
1. Extract this ZIP.
2. Upload timetable.html into the root of your CREST GitHub repository, beside index.html.
3. To make the timetable easy for students to open from the dashboard, the Weekly Timetable link shown in index_timetable_patch.txt must also be added to index.html.
4. The student page displays only entries published by the administrator.

NOTE:
This is the student timetable page package. It does not include a rebuilt admin.html because the existing admin page must be integrated without replacing your current admin features.
