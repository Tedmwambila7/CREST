Important remaining integration boundary
-----------------------------------------
The student page still uses the earlier session-token RPC flow and legacy
questions/answer_keys tables. The new staff editor writes to
examination_questions/examination_question_options. These are separate
data models. The student delivery and marking backend must be migrated to
the new model before the student portal can sit papers created by the new
Question Management page.

No Supabase database migration was executed by creating this ZIP. Run
master-code-5-polish.sql in the CREST Examination Supabase project before
using the updated examination creation form and total-mark safeguards.
